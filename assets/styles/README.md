# NIRMAAN AI Styles Directory

This directory contains the custom stylesheets and theme overrides for the NIRMAAN AI portal.

## Files

- **`custom.css`**: The core stylesheet providing:
  - Dark navy and teal/emerald color palette tokens (`#0A1128`, `#0F172A`, `#1E293B`, `#0D9488`, `#10B981`)
  - Glassmorphic translucent cards (`backdrop-filter: blur(12px)`)
  - Hero layout styles, full-width responsive header, and floating civic assistant styling
  - Severity badge pills, priority score indicators, and table styling
  - Accessible micro-interactions and transitions
