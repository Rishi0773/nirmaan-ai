# NIRMAAN AI Assets Directory

This folder holds static styling, logos, and imagery for the **NIRMAAN AI** portal.

## Subdirectories

- **`images/`**: Houses photography, civic logos, avatars, and illustration assets. See [`images/README.md`](images/README.md) for required image files, dimensions, and specifications.
- **`styles/`**: Custom CSS tokens, glassmorphism stylesheets, animations, and design overrides. See [`styles/README.md`](styles/README.md).
